## 📋 您需要做的（只需1步）

### 步骤 1: 授予本地网络权限（必需）

1. **打开系统设置**
   - 按 `Cmd + Space` 搜索 "系统设置"
   - 或点击 🍎 菜单 > 系统设置

2. **进入隐私设置**
   - 点击 **"隐私与安全性"**
   - 滚动到底部，点击 **"本地网络"**

3. **授予权限**
   找到并**勾选**以下应用：
   - ✅ **Terminal**（或您使用的终端应用）
   - ✅ **VS Code**（如果使用 VS Code）
   - ✅ **Flutter**（如果有显示）
   - ✅ **Dart**（如果有显示）

4. **关闭系统设置**

## 🎯 运行应用

完成权限设置后，运行：

```bash
cd wanderlog_app
./fix_and_run.sh
```

或者直接：

```bash
cd wanderlog_app
flutter run -d 00008150-001954293C82401C
```

## ⚠️ 如果仍然看到权限错误

1. **完全关闭终端/IDE**
2. **重新打开**
3. **再次运行应用**
